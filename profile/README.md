### Open foundations for AI in networking and security

WireSage is an open-source community building the shared tools, interfaces and evaluations for applying large language models to networking and cybersecurity: MCP servers, agents and scanners, developed in public.

Our goal is to make that work trustworthy: typed tools instead of raw shells, safe and reversible defaults, and results that anyone can inspect and reproduce.
